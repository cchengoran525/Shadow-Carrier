## 1. 坐标系、轮序与 X 型判定

**约定（全文档、固件、RK 侧一致）**：

- 车体系：**x 前、y 左、z 上**（右手系）；**wz = 绕 z 角速度，逆时针为正**（俯视 CCW）。
- 轮序固定 **FL / FR / RL / RR**（左前/右前/左后/右后），编号 w1..w4 对应设计文档 §1.1。
- **轮"正转"定义：u_i > 0 = 该轮单独接驱动时使车体向 +x（前）走**。这是全文档所有符号的唯一基准。
- 几何：**L = 半轴距**（x 方向，轮心到车心）、**W = 半轮距**（y 方向）、**r = 轮半径**。

**X 型判定**：从车顶向下看，四个轮**接地辊子轴线在地面上的投影**构成四条 45° 斜线；FL 与 RR 的辊线同在一条 "\" 对角线上，FR 与 RL 同在一条 "/" 对角线上——四条线拼成 **X**（O 型则是 FL/RR 走 "/"、FR/RL 走 "\"，围成一圈 "O"）。

```text
                    x+ (前)
                      ↑
                      │            wz(+) = 逆时针（本图面内 CCW，↺）
        y+ (左) ◄─────┼─────
                      │
                      │
    FL  ┌────────┐    │    ┌────────┐  FR
   (w1) │  M1    ╲    │    ╱    M2  │ (w2)
        │  ENC1   ╲   │   ╱   ENC2  │
        │          ╲  │  ╱          │
        └───────────╲ │ ╱───────────┘
                     ╲│╱
          ────────────┼─────────────   ← 车体横轴（y 方向）
                     ╱│╲
        ┌───────────╱ │ ╲───────────┐
        │          ╱  │  ╲          │
    RL  │  M3    ╱    │    ╲   M4   │  RR
   (w3) │  ENC3 ╱     │     ╲ ENC4  │ (w4)
        └────────┘    │    └────────┘
                      │
       图中每条 ╲ ╱ = 该轮【接地辊子轴线】的地面投影（±45°）
       FL+RR → "\" 对角线；FR+RL → "/" 对角线  ⇒  整体 = X 型
```

要点：

1. **画的是接地辊子**（轮子最下面那颗与地面接触的辊子）。"从上方看辊子纹路呈 X" 说的就是这四条投影线；平时肉眼看轮侧面看到的斜纹与之一致（同一颗辊子）。
2. 每个"轮位"的电机左右镜像安装（左侧电机正转驱动前进、右侧电机也正转驱动前进——**正负号差异全部用固件里的 `MOTOR_x_SIGN` 常量吸收，不靠接线对错来赌**，见 §4）。
3. 麦轮必须**成对购买**（左手性 ×2 + 右手性 ×2），装配口诀："FL 和 RR 同手性、FR 和 RL 同手性，接地辊线拼 X"。装反任意一颗 = 变成局部 O 型，横移方向立即错（§3 判定表可当场检验）。

## 2. 运动学推导（从"辊子不打滑"一条约束推起）

### 2.1 单轮约束

麦轮 = 主轮盘（轴沿 y）+ 边缘一圈 45° 辊子。辊子可绕自身轴**自由空转**，所以轮-地接触中：

- **沿辊子轴方向**：辊子空转吸收一切速度 → **不构成约束**；
- **垂直辊子轴方向（地面内）**：辊子做纯滚动 → 接触点材料速度为零。

设轮 i 接地辊子轴的地面投影单位向量 e_i = (e_ix, e_iy)，与 x 轴夹角 γ_i（±45°）。接触点材料速度 = 轮毂下端速度（含车体运动 + 主轮自转反冲）+ 辊子自转贡献（**垂直于 e_i，投影后消掉**）。沿 e_i 投影，只剩：

```text
e_i · v_i = r·φ̇_i · e_ix        （φ̇ = 主轮角速度，v_i = 该轮接地点的车体速度）

⟹  φ̇_i = ( v_ix + tanγ_i · v_iy ) / r
⟹  轮缘线速度  u_i = r·φ̇_i = v_ix + tanγ_i · v_iy        …(★)
```

**(★) 是全部推导的根基**：轮速 = 接地点速度的 x 分量 + (±1)×y 分量。γ 的符号（"/" 还是 "\"）逐轮给出。

### 2.2 四轮接地点速度（刚体平面运动）

v_i = v_body + wz ẑ × r_i，即 **v_i = (vx − wz·y_i, vy + wz·x_i)**：

| 轮 | 位置 (x_i, y_i) | v_ix | v_iy | 辊线 tanγ_i |
|---|---|---|---|---|
| FL | (+L, +W) | vx − W·wz | vy + L·wz | −1（"\"） |
| FR | (+L, −W) | vx + W·wz | vy + L·wz | +1（"/"） |
| RL | (−L, +W) | vx − W·wz | vy − L·wz | +1（"/"） |
| RR | (−L, −W) | vx + W·wz | vy − L·wz | −1（"\"） |

### 2.3 逆运动学（vx, vy, wz → 四轮线速度）

把上表代入 (★)（u 单位 m/s；K ≡ L + W）：

```text
u_FL = vx − vy − K·wz        …(1)
u_FR = vx + vy + K·wz        …(2)
u_RL = vx + vy − K·wz        …(3)
u_RR = vx − vy + K·wz        …(4)
```

（与 WPILib `MecanumDriveKinematics` 的 X 型默认式逐项一致——独立推导后核对，非照抄；RM 调研 §1.1 草案的 k 即此处 K = L+W。）

**物理自检**（可在架空时目视验证）：wz>0（逆时针/左转）时左轮退、右轮进——与差速坦克左转完全同号，只是每轮各叠加了 vy 项。

### 2.4 正运动学（四轮 → vx, vy, wz）

系数矩阵四列互相正交，最小二乘解即精确解（四轮速度一致时）：

```text
vx = (  u_FL + u_FR + u_RL + u_RR ) / 4
vy = ( −u_FL + u_FR + u_RL − u_RR ) / 4
wz = ( −u_FL + u_FR − u_RL + u_RR ) / (4K)      K = L + W
```

### 2.5 X 型 vs O 型（一句话 + 为什么）

> **一句话：O 型把每轮的 vy 项符号镜像（tanγ 全体反号），导致自转系数从 (L+W) 坍缩为 |L−W|——L≈W 的方形底盘几乎（L=W 时精确）无法靠轮子原地转，而 X 型平移与自转满秩解耦。** 故工程上麦轮一律 X 型；本文只实现 X 型。

（推导：O 型 u_FL = vx + vy + (L−W)wz 等，wz 列系数 ±(L−W)；本项目 L=120、W=135 mm，|L−W|=15 mm vs K=255 mm，自转权限差 17 倍。）

### 2.6 诚实备注：45° 是"地面投影角"还是"立体角"

真实麦轮的辊子轴与轮轴的**立体夹角**为 45° 时，其**地面投影角**是 35.26°（tan = 1/√2），(★) 中横向耦合系数 c = tanγ_投影 < 1。后果（代入 (★) 可算）：**vx 精确、无轴间串扰，只有 vy 按 1/c、wz 按 K/(W+cL) 被等比放大**——轮速闭环会把轮速钉死，故这只是两个标量标定因子。固件留 `CAL_VY_SCALE` / `CAL_WZ_SCALE`（默认 1.0，落地标定填实测值）。**标定前一切符号与方向结论不受影响**（缩放不改符号）。

## 3. 符号表（评审核心表 —— 12 格对应 12 组单测断言）

**u_i 符号 = 该轮正转(+)/反转(−)/停(0)**；前提：X 型 + §1 的"正转=驱车前进"定义。

| 指令（其余分量为 0） | FL | FR | RL | RR | 物理效果 |
|---|---|---|---|---|---|
| **vx > 0（前进）** | **+** | **+** | **+** | **+** | 四轮全正转，直行 |
| **vy > 0（左移）** | **−** | **+** | **+** | **−** | 对角同号：FL/RR 退、FR/RL 进，车向左平移 |
| **wz > 0（逆时针/左转）** | **−** | **+** | **−** | **+** | 左侧退右侧进，原地左转（同差速） |

派生核对（不必背，出问题时查）：

- 右移（vy<0）：符号表整行取反。
- 顺时针（wz<0）：整行取反。
- 一般混合指令：四轮各自代数叠加（逆运动学是线性的）。
- **装配自检**：发纯 vy>0，若车转圈或斜走 → 有轮装错手性（变局部 O）；发纯 wz>0，若车横漂 → 同理。这是上电第一步的"1 分钟体检"。

## 5. 控制环（100Hz 主环）

```text
RK(10Hz) ──MEC/DIFF──► 命令层：解析+限幅+450ms 超时看守
                          │ (vx,vy,wz) 目标
                          ▼
                 逆运动学 (1)-(4) → 四轮目标 u_i (m/s)
                          │ 饱和/反解饱和：四轮同比例缩放（保方向，弃幅值）
                          ▼
        ┌──────────── 100Hz 轮速环 ×4（PCNT 读数 → u_meas → PID → duty）────────────┐
        │  PID：位置式，P+I+D(对测量微分)，积分钳位 + 饱和时停积分（anti-windup）     │
        │  输出 duty ∈ [−1,1] → 符号-占空比写 PWM/DIR，输出变化率限制（复用 V1 缓启）│
        └──────────────────────────────────────────────────────────────────────────┘
                          │
        遥测 10Hz：ENC（四轮实测 m/s，带 ms 时戳）／ HDG（MPU6050，可用时）
```

- **轮速环 100Hz（10ms 节拍）**：S3 240MHz 双核，4×PID + PCNT 读数 < 0.1ms 负载。速度测量加一阶 EMA（α=0.5 占位）抑制 0.019 m/s 量化。
- **饱和与反解饱和（desaturation）**：目标四轮 |u| 最大值超 `WHEEL_V_MAX` 时，**四轮乘同一系数 k = V_MAX/max|u_i| 再进 PID**——方向（vx:vy:wz 比例）严格保留，只缩幅值。绝不逐轮独立钳位（那会改变合成方向，横移变斜走）。同时目标 twist 整体限幅：`VX_MAX=0.8 m/s`、`WZ_MAX=2.0 rad/s`（§12.3 巡航上限）。
- **航向环**：骨架预留接口（`USE_MPU6050 0` 默认关）。启用时为**慢速外环**（10Hz 计算，wz 修正 = −Kp·Δyaw，限幅 ±0.3 rad/s），带宽纪律按 §5.4.6（航向环 ≪ 视觉环）。PID 先不写死参数，占位待 bring-up。
- **命令超时 450ms**（沿用 V1 `MOTOR_COMMAND_TIMEOUT_MS`）：任何运动命令刷新时间戳；超时 → 目标清零 + 电机滑行 + PID 复位。`PING` 不刷新。
- **输出缓启**：duty 每拍变化限幅（复用 V1 ramp 思想，步长占位 0.08/tick），兼作防堵转冲击。

## 6. 串口协议（USB CDC，ASCII 行，`\n` 结尾，115200）

新增/兼容全表（**MEC/DIFF/STOP/PING 大小写不敏感，与 V1 解析器同样 trim+upper**）：

| 方向 | 命令 | 语义 | 单位/范围 | 示例 |
|---|---|---|---|---|
| 下行 | `MEC <vx> <vy> <wz>` | 车体系速度向量 → 逆解四轮 | **m/s, m/s, rad/s**（float，3 位小数）；超限整体等比限幅 | `MEC 0.40 -0.15 0.00` |
| 下行 | `DIFF L<n> R<n>` | **V1 兼容**：u_L=n/255·MAX, u_R=n/255·MAX → vx=(uL+uR)/2, **wz=(uR−uL)/轨距**, vy≡0 → 再走 MEC 逆解 | n∈[0,255]（V1 语义）；`DIFF_MAX_MPS`、轨距常量占位 | `DIFF L120 R150` |
| 下行 | `MOVE F/B/L/R <n>` | V1 兼容：F/B→vx=±n/255·MAX；**L/R→原地转 wz=±PIVOT_WZ**（V1 搜索转向语义） | n∈[0,255] | `MOVE R 240` |
| 下行 | `STOP` | 目标清零、电机滑行、故障锁清零 | — | `STOP` |
| 下行 | `PING` | 回 `PONG`（不刷新超时） | — | |
| 上行 | `ENC <ms> <u1> <u2> <u3> <u4>` | 四轮实测线速度（10Hz，带 ms 时戳，§5.4.8 全线时间戳化纪律） | m/s ×3 位小数 | `ENC 123456 0.401 0.398 0.400 0.399` |
| 上行 | `HDG <deg> <gz_dps>` | 航向与角速度（10Hz；仅 IMU 启用时发） | deg（−180..180）、deg/s | `HDG -12.34 0.8` |
| 上行 | `TEL <key> <…>` | 保留：启动 `TEL BOOT <fw>`、故障 `TEL FAULT <code>`；V2b 起 STS3215/INA219 遥测走此前缀 | — | |

**与 §2.5 草案的两处显式修订**：① MEC 单位定为 **SI float（m/s, rad/s）**而非 cm/s——RK 侧控制律全是 SI，cm/s 整数在 wz 上浪费精度且多一次换算；② DIFF 兼容的 wz 换算用**差速轨距**（=2W 占位 0.27m）而非麦轮 K——因为 V1 客户端（follow_controller 弧线跟随）调参锚定的是"差速行为"，这样同一条 `DIFF L100 R150` 在新底盘上的转弯半径与 V1 最接近。轮速目标层面它等价于"左对同速、右对同速"，已是轮速闭环的一部分（不是开环 PWM 直通）。

## 8. 标定与验收（V2a 台架→落地，`V2V3_ROADMAP` §2 对齐）

1. **架空方向表（上电第一件事）**：轮子离地垫起，逐条发 `MEC 0.2 0 0` / `MEC 0 0.2 0` / `MEC 0 0 0.8`，目视核对四轮转向 == §3 符号表（12 格）；不对 → 改 `MOTOR_x_SIGN`。再手转每轮看 `ENC` 计数符号，定 `ENC_x_SIGN`。
2. **CPR/轮径标定**：发 `MEC 0.2 0 0` 架空转 10s，记 PCNT 总计数 → counts/转应 ≈1320（差 >5% 改 `ENC_CPR`）；落地推直线 2m 记计数 → 反推轮径（差 >2% 改 `WHEEL_DIAMETER_MM`）。
3. **落地 1m 三动作**：前进 1m / 左移 1m / 原地 ±90°，各 3 次取中位：终点偏差 <0.1 m、航向漂 <5°；横移若恒定偏航 → 量 `CAL_VY_SCALE`（§2.6）。
4. **5m 直线**：`MEC 0.35 0 0`（开航向环）5m，横向偏差 **<0.3 m**（roadmap V2a 验收线）；再关航向环跑一次记录自然漂（基线数据）。
5. **横移漂移**：`MEC 0 0.25 0` 走 3m，前进向偏差 <0.3 m，超差先查辊子磨损/地面，再动 CAL_VY。
6. **DIFF 回退演练**：面板切 `DIFF` 模式跑弧线跟随一分钟（V1 行为），确认一键回退可用（§5.4.6-3）。

## 9. 上实车前必须实测确认的 5 个点（bring-up 清单，一票否决项）

1. **轮序**：四轮装位与 FL/FR/RL/RR 及手性一一对应——接地辊线拼 X（§1 图）；发纯 vy/wz 按 §3 表逐格验收。
2. **辊向**：每颗轮的 45° 斜向与 §1 图一致（有装反/左右手性发错即变 O，横移直接错向）——纯 vy 测试一票判定。
3. **极性**：逐轮点动确认 `MOTOR_x_SIGN`（正转=驱车前进）、手拨轮确认 `ENC_x_SIGN`（正转计数增加）；编码器 A/B 相接反会使计数反向——同样用 SIGN 宏吸收。
4. **CPR**：实测 counts/轮轴转（预期 1320=11×4×30；廉价霍尔板存在 2 边沿/磁极的缩水版，实测差 2 倍就是它）。
5. **轮径**：实测滚动直径（80mm 麦轮受辊子公差影响，±2mm 很常见）——里程计与速度标定的分母。

> 以上任何一项未确认前，固件里所有几何/极性宏都是占位（`MecanumConfig.h` 全部标 TODO），**符号逻辑（§3 表）与代码的正确性不依赖这些占位值**——这正是离线单测（`tests/test_mecanum.cpp`）覆盖的内容。
