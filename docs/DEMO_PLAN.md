## 1b. 分镜 仿真 vs 实机 现状对照（2026-10-08，统筹）

> 结论：**仿真 = 100%（剧本/逻辑/接口全绿）；实机 ≈ 70%；整体 ≈ 78%**。
> 仿真是**逻辑与接口彩排**（kinematic 无物理 + 几何真值合成检测），**不验证**控制动力学/感知噪声/时序抖动 —— 风险已收敛为「**sim→real 移植**」。

## 2. 实机移植清单（仿真→实机的差异项）

1. **owner.source 拨盘**：板上 `hri_params.json` 把 `owner.source` 从 `none` 拨到 `file`（A1.2 消费端已在仿真验证）。拨盘前后各跑一遍双人对抗。
2. **跟随车距**：仿真用地面真值做了 2.6/3.0m 车距保持；实机 follow_controller 是恒速推进（v3 原版"距离由人自行掌握"）。
   - ⚠️ **统筹裁定（10-08）**：**h 只能做"近距急停兜底"**（bbox 高度 > 阈值 → STOP/后退），**不能当测距环** —— 08-24/10-03 已两次证伪 bbox 高度测距（半身/腿部失真、近距饱和）。
   - **距离源优先级**：`[世界] dist_m`（112 角生产标定 ≤2%）> `tracker r`（云台 M2）> `h` 兜底。
   - demo 层面**不要求精确保持 2.5m**：加 h 急停 + 主人自控步速（剧本回程本就容许 1.7–3.5m）即可；`dist_m` 做单向"太近→减速"是增强、非阻塞（等 @世界 确认 FOLLOW 期 dist_m 可得性与频率）。
   - 这是实机侧唯一建议的代码改动（A2 前）。
3. **HIDE 选点**：实机由滚动地图的 free_sectors 驱动 sector_score；走廊场景需确认 geometry_daemon 在走廊里能稳定产出门/自由扇区（CALIBRATION.md 流程跑一遍）。
4. **救援凝视 / 搜索转身**：⚠️ **统筹裁定（10-08）：demo 默认不依赖云台运动** —— 舵机受损、换舵机延后到 demo 后，把 demo 正确性押在坏舵机上风险过高。实机对应改为：
   - **云台固定居中（默认）**；救援式凝视（W1）标为**可选增强**（仅当新舵机/demo 前舵机健康时开启）。
   - §1 分镜的"搜索转身"用**底盘原地转**替代（`/turn` 已就绪，IMU 闭环）。
   - 动线要求：主人主要在车前方（走廊直线），避免大幅横向出 FOV。
   - **验收动作**：Webots 跑一遍"云台冻结"版剧本，确认 8 分镜仍通过。
5. **IMU 航向保持**：走廊长直道是 IMU 航向环的用武之地（imu_daemon 已部署），demo 前验证直线 5m 偏差 <0.3m。

## 4. 视频能展现、但台词不会明说的能力

1. **0.8TOPS 上的多模型调度**：YOLO 快环 11fps + YOLO-World 开放词汇慢环 + 几何环三线同跑——画面只有"车躲到了墙根"，背后是 NPU 上三个模型的实时预算分配。
2. **标定链的精度兜底**：车停的位置"恰好"离门 9m、离饮水机 1m——背后是内参三方互证（fx=508, 方位角误差 0.08°）+ PnP 极坐标（距离误差中位 3.23%）。
3. **跨进程契约工程**：owner.json / grid.json / 串口协议四条冻结接口让四条线互不踩——视频里看不到，代码仓库门面（README+架构图）能看到。
4. **A/B 实验方法论**：救援式凝视 vs 持续追踪的对照实验（四条扰动通道归因）——面试/套磁里最稀缺的"负结果+归因+重构"素材。
5. **黑匣子全程留痕**：demo 视频同步配一张"状态转移时间轴图"（jsonl → 时间轴），把 95s 剧本变成一张可讲解的系统图——这是给老师看的第二材料。
6. **仿真-实机同构验证**：Webots 里同一套状态机/协议先跑通再上板——展示工程判断力（"什么时候该用仿真"）。

## 5. 作品延展性（demo 之后的三个方向）

- **作品集轨**：本 demo 直接产出 5 个面试故事——NPU 边缘管线调优（0.8→11fps）、单目极坐标世界快照（PnP 3.23%）、救援式凝视 A/B、锁主三层防御、HRI 黑匣子闭环。每个故事配 STAR 卡片。
- **科研轨**：走向"真世界模型"的第一步=路径记忆拓扑图（demo 动线存为节点+边，重访先验）——走廊场景天然是拓扑演示场；切口二（社交信号主动服务）的黑匣子数据从本 demo 开始持续采集。
- **专利/产品轨**：①"多信号融合用户锁定与跟随方法"（机主原则 L0-L3 即权利要求层级）；②"云台-底盘级联视野保持方法"（A/B 数据=创造性论据）；产品化试水=防丢跟随模块（购物车/行李箱），demo 视频发 B 站/小红书做零成本需求调研。
