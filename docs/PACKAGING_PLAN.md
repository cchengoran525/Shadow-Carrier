> 写于 2026-10-08。目的：把**同一个仓库、同一批实测数据、同一套 demo 物料**，分别包装成作品集、科研、专利产品三条轨道的可交付物，实现"一鱼多吃"、边际成本递减。
>
> 与既有文档的关系：是 `docs/REVIEW_AND_SEMESTER_PLAN.md` 第三部分（三轨初稿）的**展开与定稿**；科研轨主线严格对齐 `docs/RESEARCH_POSITIONING.md` 的"主动分离 / 四条可验收证据"；演示物料沿用 `docs/DEMO_PLAN.md`；产品/寒招沿用 `docs/V2_CHASSIS_GIMBAL_DESIGN.md §12/§13`。
>
> **本文只做包装 / 叙事 / 物料规划，不含技术开发。** 凡是需要写代码或做实验才能兑现的，都明确标为"扩展/设想"。

## 0. 总原则

1. **一鱼多吃**：三轨共用同一套底层资产，三轨的动作里凡标 `[复用]` 者不产生新工作量，只做重新叙事/排版；标 `[少量新增]` 者控制在数小时~数天；只有扩展清单才可能引入成规模工作。
2. **优先级 = 科研 > 专利 > 作品集**（沿用 REVIEW §3；按升学/套磁收益排序）。冲突时高优先级先占资源；但**共同前置（10 月底 demo / 一页纸 / 视频 / README 门面）三轨共用，必须先做**，它不属于任何单轨。
3. **诚实标注体系**：全文每个资产/交付物贴三级标签，凡未标注的"能做到"一律视为不存在。
   - `✅ 已实现`：真机/板上可复现，有实测或数据。
   - `🔧 半成品`：代码/仿真就绪，实机未验，或仅单点通过、全链路未串。
   - `💭 设想`：仅设计稿 / 占位 / 路线图，无实现。
4. **不营销**：报"问题重述 + 已有零件 + 明确缺口"，不报"已经能做主动分离"。仿真结果一律标注"仿真 = 逻辑/接口验证，不等于实机"。
5. **节点对齐**：10 月底 demo + 套磁（硬节点）；寒假寒招；"大四前"做出真正的搭子。

### 4.3 主线叙述（必须收窄，不泛谈）

> **一句话**：SC 用**"主动分离"这一负向策略**，把"动态人群中鲁棒跟随"（难、卷、容易输）**重述**为"伴随机器人的**分离事件管理**"（可做、少人做、能赢）。

- 别人的题：*如何在全动态人群里鲁棒跟随？* → 我们的题：*伴随机器人如何管理分离事件？*
- **全部研究内容 = 三个"时机"问题**：**Pre** 何时分（唯一新零件）、**During** 何处等（复用 HIDE/affinity）、**After** 何时回（复用认主+跟随）。
- **两根柱子**：世界模型（等待参照系）+ 认主锁主/跟随（负责"回来"）；柱子在手时，新做的只有 **Pre 触发判据**。
- **不是回避科学，是换一个能赢的提问方式**（RESEARCH §2）。文献对标（RESEARCH §8b）：Follow-Bench / SDA / EscortE / GUIDER / arxiv 1909.06087 / social yield / legibility。
- **差异点一句话**：*把"退避/让开"从失败处理提升为一等公民行为，并用它替代"穿越人群"的难题。*
