# 视频 2 — 愿景片「逛街搭子」分镜（简笔画风格）

> 定位：面向**完整产品愿景**的情绪片，回答"这东西最终是什么样、和用户是什么关系"。
> 时长目标 **1'35"–1'45"**，16:9（可选 9:16 竖版供小红书/B 站需求调研，见 README 产品轨）。
> 全片**零功能术语、零 UI、零数据**——能力全部用行为演出来，字幕只写人的话。

---

## 1. 叙事弧（三幕）

1. **问题与登场**（镜 1–3）：拎满双手的狼狈 → 一句愿景 → 俯视开场，人与车一起上路。
2. **同行（能力潜台词）**（镜 4–11）：开门、路人、奶茶、人群分离、接物——每个场景背后是一项能力，但**不说破**。
3. **零负担与落版**（镜 12–14）：主人双手插兜回扣开场 → 路径"走"出名字 → README 引言收尾。

---

## 2. 风格指南

| 项 | 规格 |
|---|---|
| 画布 / 帧率 | 1920×1080；手绘 12fps（输出 24fps，"一拍二"） |
| 色板 | 纸底 `#FAF6EF` / 墨线 `#2F2A26` / **唯一强调色琥珀橙 `#F59E42`**——只给 SC 的眼灯、路径线、交接点 |
| 线条 | 等宽 3–4px 圆头；全程轻微 **boiling 抖动**（±1px、2 帧循环），营造"活的铅稿"感 |
| 转场 | 纸张擦除 / 线条解体重组；不用叠化（除镜 12 呼应开场那一次） |
| 字体 | 手写感中文：站酷快乐体或霞鹜文楷（均可商用免费） |
| SC 角色设定 | 圆角方盒车身 + 两点眼灯 + 两轮 + 顶部浅托盘 + **侧面小挂钩**；无脸，**眼灯是全片唯一"表情系统"**：常亮=跟随 / 转向=注视主人 / 弯弧=开心 / 变浅=待机让行 |
| 主人设定 | 线稿小人（性别中性），固定发型+背包做识别锚点；身高 ≈ 5.5× 车高 |
| 音乐 | 85–95 BPM 轻钢琴 + 口哨/尤克里里；音效：铅笔沙沙、灯"叮"、取餐铃、纸页翻动 |

套磁时老师若问"愿景片里哪些做出来了"，这张表就是你的回答底稿：

| 场景 | 背后能力 | 状态 |
|---|---|---|
| 镜 3/5 跟随与绕行 | FOLLOW + 路径重规划 | V1 已有（sector_score 亲和度已上线） |
| 镜 4 窄口贴边 | 动态路径 / 社会让行 | V1 部分 / V2 绕行型（需麦轮） |
| 镜 6 挂奶茶 | 隐式交互（README 核心洞察） | RECEIVE 持物识别已真机验证 |
| 镜 7 人群分离 | **Proactive Separation**（Pre/During/After） | V2/V3 封存在研（DEFERRED_WORK.md）——愿景片的灵魂正好是下一步的研究主脊 |

## 5. 制作管线（三条路，推荐组合拳）

| 管线 | 做法 | 优劣 | 用在哪 |
|---|---|---|---|
| **A. AI 图生视频（主力）** | 每镜先做**首帧**（MJ/即梦/Krea 出线稿图）→ Kling / 即梦 / Veo / Runway 图生视频 5–10s → 剪映合成 | 快、量大；一致性靠首帧+参考图锁 | 镜 3–8、11–13 的"行走/分离/接物" |
| **B. 手绘逐帧（点睛）** | Procreate 12fps 逐帧，或 AE shape layer | 质量最高、最费工 | **眼灯表情、连线淡入淡出、小星花**——这几个 AI 做不准，手绘 30 帧搞定 |
| **C. 代码动画（兜底+预演）** | SVG/Canvas 或 Python 绘帧 → ffmpeg 合成 | 全可控、零成本，适合规则运动 | 路径 draw-on、文字落版（镜 13）、**先出 animatic 验证节奏** |

**推荐组合**：先用 C 出整条 animatic（含音轨节拍点）→ 定稿节奏 → A 管线逐镜生成 → 关键表情用 B 修 → 剪映/PR 合成。纸上纹理统一在后期叠一层（混合模式"正片叠底"），能把 AI 素材的"塑料感"压回手绘感。

### AI 一致性三招
1. **角色设定图先行**：主人和 SC 各出一张三视图定稿，之后每镜生成时都作为参考图垫底（MJ `--cref` / Kling 参考图 / 即梦主体一致性）。
2. **风格词尾缀固定**：每条 prompt 结尾粘同一段风格串（见 §6 模板）。
3. **一镜一判定**：AI 每镜生成 3–5 候选，只挑线稿风格稳的；线稿黑白简单场景，AI 出错率远低于彩色写实，这是选简笔画风的工程红利。

## 6. AI 提示词模板

### 首帧图 prompt（MJ / 即梦 / Krea）
```
minimalist black-ink line drawing on warm white paper, hand-drawn sketch
animation keyframe, [场景描述], a small rounded cart robot with two dot eyes
and a side hook, thin clean ink lines, no shading, no color fill, subtle
paper texture, consistent character design --ar 16:9 --style raw
```
负向词：`color, 3D render, realistic, detailed background, text, watermark`

### 图生视频 motion prompt（Kling / Veo / Runway）
```
Hand-drawn 2D animation, lines slightly wobbling (boiling line effect),
[运动描述：the cart follows the person smoothly forward / the cart glides
aside and stops beside the lamppost], camera slowly tracks, gentle motion,
12fps feel, white paper background stays static
```

### 分镜示例（挑 4 个最难镜头）
| 镜 | 场景描述段（填入模板） |
|---|---|
| 3 | top-down view of a pedestrian street drawn in thin ink lines, a person walking forward followed by a small rounded cart robot, a dashed path line trailing behind them |
| 7 | the cart robot glides aside to a lamppost and stops while a small group of sketched pedestrians walks past the owner, overhead view |
| 11 | close-up: the smiling owner hands a shopping bag down to the small cart robot which has rolled slightly forward |
| 13 | the dashed path behind them curves into handwritten letters "Shadow Carrier" |

### 角色一致性设定图 prompt
```
character design sheet, minimalist ink line drawing: (1) a small rounded
cart robot with two amber dot eyes, side hook, two wheels, front/back/top
views; (2) a young person with a backpack, front/side view; warm white
paper background, clean thin lines --ar 16:9
```
