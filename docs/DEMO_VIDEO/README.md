## ZCode 在这套视频制作里能干什么

**已交付**：两支片完整剧本/分镜/字幕文案/风格指南/AI 提示词（本目录三个文件）。

**接下来随时可做（说一声即可）**：
1. **黑匣子时间轴图**：从 `run_demo` / `pose_offering_test_*.jsonl` 日志生成状态转移时间轴（SVG/PNG）——视频 1 的差异化底牌，也是给老师的独立第二材料。
2. **sector_score 扇形亲和度 overlay**：代码生成带 alpha 的 PNG 序列，AE 直接导入叠加。
3. **HUD 素材包**：锁定框/标签/连线的 SVG+PNG（AE 素材层），配色按 VIDEO1 §3 规格。
4. **视频 2 animatic**：Python/SVG 按分镜表逐镜绘帧 + ffmpeg 合成带时间码预览片，先验证节奏再投入 AI 生成（省重roll 成本）。
5. **逐镜 AI 提示词批产**：14 镜首帧图 + motion prompt 全量填好（VIDEO2 §6 已给模板和示例，可扩成全表）。
6. **实拍素材后处理**：ffmpeg 剪切/拼接/变速/调色 LUT/字幕烧录/压缩到邮件 <10MB/批量转码、素材命名与目录整理。
7. **双语字幕**：SRT/ASS 生成与烧录，静音可看的中英硬字幕。
8. **套瓷落地页**：单页 HTML 嵌两支视频 + 项目摘要 + 仓库链接，邮件里放一个链接全说完。
9. **拍摄执行单**：机位/道具/人员 checklist 表格化，拍摄当天打勾用。

## 通用规范

- 母版 ProRes 422 1080p24；发布版 H.264 CRF 20 <10MB；短版 720p <5MB。
- 全程硬字幕（老师经常静音看），封面帧带标题压角。
- 素材目录：`demo_video_footage/{raw,ai,audio,export}/`，命名 `v1_shot05_take2.mp4`。
- 诚实红线：真机没跑通的镜头一律标「仿真演示」（Webots 画面现成可录屏）。
