# 视频 1 — 功能实证片（实拍 + 动效）剧本

> 定位：给世界模型 / 无人驾驶 / 人机交互三位老师看的**证据片**。
> 主版 **72s**（16:9），另剪 **30s 短版**作邮件正文预览。全程硬字幕，**静音也能看懂**。
> 核心策略：**不念参数，让证据自己说话**——真实系统画面优先、仿真诚实标注、黑匣子全程可视。

---

## 1. 叙事三条铁律

1. **真实系统画面 > 伪造 HUD**：锁定框优先用车上 YOLO 检测的真实录屏画面（控制页/取流），AE 只做描边美化、标签和稳定。老师一眼能看出真假。
2. **仿真诚实标注**：真机未跑通的镜头（HIDE 端到端、APPROACH 动作层）用 Webots 画面并打「仿真演示」角标，或等 A1.3 完成后补拍。套磁片造假是自杀。
3. **黑匣子可视化**：底部常驻一条**状态机时间轴**（FOLLOW→WAIT→HIDE→RECEIVE…），数据直接从 `run_demo` / jsonl 日志生成——这就是 `DEMO_PLAN.md` §4.5 说的"给老师的第二材料"，在片子里先亮出来。

## 3. AE 动效规格

| 组件 | 规格 | 素材来源 |
|---|---|---|
| 锁定框 | 橙 `#F59E42` = 主人（4px 描边 + 角标折角），灰 `#9CA3AF` = 路人；标签等宽字体 24px，黑底 70% 圆角条 | 优先真实录屏；AE 用 Mocha 平面跟踪贴框 |
| 状态机时间轴 | 底部 60px 条，节点圆点 + 状态名，经过时点亮 + 发光脉冲 | **从 jsonl 日志代码生成**（可交给我做，输出 SVG/PNG 序列） |
| sector 扇形图 | 半透明扇区环 + 选中扇区实色 + 分数气泡 | 代码生成带 alpha 的 PNG 序列，AE 直接叠 |
| 数据浮标 | `11 FPS` `RK3566 · 0.8 TOPS` `PnP 3.23%`，出现在对应 B-roll 特写（NPU 板、接线、轮子） | AE 文字动画即可 |
| 转场 | 硬切为主，分屏/章节用 200ms 线性擦除；不加花哨转场 | — |

工程结构建议：`01_FOOTAGE / 02_OVERLAY / 03_AUDIO / COMP_master`，overlay 全部预合成，方便改一版全片联动。

## 4. 拍摄执行

### 场地动线与机位（宿舍走廊，白天拍——夜景幻影率历史 95/98 帧，一律白天）

```
门 ═════════════════════════════════ 走廊尽头（饮水机 / 冰箱）
 ▲路人入场          [机位C 高机位俯拍×2处]
                    ┌───┐
        主人 ●──→   │SC │    [机位A 跟拍·手持稳定器]
                    └───┘    [机位B 固定广角全景(拍HIDE)]
```

- **机位 A**（跟拍）：手机 + 稳定器，拍镜 1/3/7/8。
- **机位 B**（固定广角全景）：三脚架，一镜到底拍 HIDE 全过程——"车自己挪走"必须被全景看见，这是全片说服力核心。
- **机位 C**（高机位俯拍）：梯子上手机固定俯拍绕障/掉头，给 AE 路径叠加用。
- 另录：**车载检测画面录屏**（镜 3/6 的真实框）、**Webots run_demo 录屏**（镜 9）、桌面 B-roll（NPU 板/接线/轮子/螺丝特写）。

### 道具与人员
购物袋×2、水瓶（递物道具，**不用果冻**）、认主用鲜艳衣物、扮演路人同学 1 名（固定路线，与主人保持 >1.5m）。

### 拍摄顺序（按系统就绪度）
1. **先拍已验证镜头**：镜 3（跟随）、4（判停）、7 特写（RECEIVE 已验部分）、B-roll。
2. **A1.3 动作层跑通后**（10 月中冻结前）：镜 5（HIDE）、7（逼近接物）、8（回程）。
3. 每个镜头 **2–3 takes**，当场回放检查 bbox 是否稳定再换镜。

### 风险对照（来自 DEMO_PLAN §3）
白天拍 / 路人固定路线 / 弯腰动作幅度小 / 递物用高置信道具 / 彩排 2 遍同机位 / 拍摄当天备手动模式。**这套视频本身就是降级预案的"视频兜底"层**——万一 demo 当天翻车，片子里已有完整证据链。

## 5. AI 生成使用点

只用在三处，其余全实拍（真实感是这片子的命）：
1. **片头 logo 演绎**（4s）：AI 图（产品 hero）→ 图生视频微动 + 标题浮现。
2. **产品 hero 补拍**：实拍车丑/光线差时，AI 渲染干净 hero 镜（MJ/即梦出图 → Kling 5s 微动），仅用于镜 2/10。
3. **无**。功能演示镜头一律真机或 Webots，AI 视频只做氛围不做证据。
