# 实地测试与 demo 录制方案（FIELD TEST PLAN）

> 写于 2026-10-20（HEAD `7b4ddc5`）。距 10-31 demo **11 天**。
> 用途：把"能跑"变成**可验收、可复现、可拍**。每个场景一张卡：布置 → 步骤 → 成功标准 → 失败/中止 → 记录。
> 配套：`DEMO_PLAN.md`（8 分镜）、`ARCHITECTURE.md`（接口）、`COORDINATION_REVIEW.md`（缺口）。
> 阈值来自代码实测常量：`BASE_SPD=220`、`MIN_SPD=120`、`PIVOT_PWM=190`、`PIVOT_RATE_DPS=174`、`NEAR_STOP_M=0.7`、`LOST_TIMEOUT_S=2.4`、认主 `3s/~12 样本`、HRI `static_need 5s / hide_after 20s`。

---

## 0. 使用方式

1. **先 P0 后 P1**：P0 不过，不往下走；P1 依赖 HRI/动作层接线。
2. **每天开场先跑 T0**（链路 smoke），FAIL 就先修链路。
3. **每个场景至少 3 次**；记"3/3、2/3"而不是"感觉可以"。
4. 失败也记录：失败帧、日志、现场照片——失败数据是 demo 视频的 B-roll 和套磁素材。

## 2. 统一度量口径（避免"各说各话"）

| 指标 | 定义 | 怎么量 |
|---|---|---|
| 人车距离 | 车体前缘到人脚的地面距离 | 地面胶带 + `range_from_box` 日志 + 视频抽帧三方交叉 |
| 车速 | 5m 平均速度 | 秒表 ×3 / 视频时间戳 |
| 主人在画面 | 该帧存在主人 bbox | `owner.json` 或 `/api/detections` 抽帧 |
| 锁定正确 | bbox 与主人真值 IoU ≥0.3 | 人工标注 + `owner.json` 回放 |
| 横向净空 | 车体最外沿到人的最小距离 | 卷尺（静态标记）+ 视频 |
| 事件时刻 | 状态切换/停/转/丢 | `hri_logs/*.jsonl` + `journalctl -u rk-control` |
| 转向速率 | 原地转 °/s | T0b 实测（3 次取均值） |
| 遮挡时长 | 主人 bbox 连续缺失时长 | 视频逐帧 + dets 时间戳 |

**判定原则**：**视频能看见 + 日志能对上 + 卷尺能量到**，三者至少两项一致才算过。

## 3. 场景矩阵

### T0 · 链路 smoke（P0，5 min）
**布置**：车放起点，人站正前 2m。
**步骤**：依次发 `PING` / `MOVE F 120` / `STOP` / `MOVE L 120` / `STOP`；看 `/api/detections`、`imu.json`、`health_check.sh`。
**成功标准**
- health_check **FAIL=0**；
- 四个动作都有物理响应，`STOP` 在 0.5s 内停；
- dets fps ≥10、age <200ms；IMU age <1s。
**失败/中止**：C3 不枚举、相机黑屏、服务不 active → 先修链路，不进入后续场景。

### T0b · 原地转标定（P0，10 min）
**布置**：空旷平地，地面贴 0°/90°/180° 参考线。
**步骤**：`/turn_pivot`（或 `MOVE L/R` 定时）转 90°、180° 各 3 次；秒表 + 视频量角度。
**成功标准**
- 实测角速度与 `PIVOT_RATE_DPS=174` 偏差 ≤15%；
- 90°/180° 角度误差 ≤10°；同向重复性 ±5°；
- 若超差：更新 `PIVOT_RATE_DPS`，并记入 EXCHANGE。
**记录**：每次的角度、耗时、PWM、电池电压。

### T1 · 认主 enroll（P0，5 min）
**布置**：主人穿**鲜艳上衣**，站 1.5–2m，正对相机；路人站画面外。
**步骤**：启动跟随 → 3s enroll → 主人左右移动 2m → 路人入画 3s → 主人出画 3s 再回。
**成功标准**
- `[owner] enroll samples ≥8`；
- `owner.json` 在 5s 内出现，score ≥`SCORE_MIN(0.40)`；
- 路人入画 3s **不写 owner.json、不触发换主**；
- 主人出画 3s 回来后 **≤3s 重锁**。
**失败/中止**：`samples=0` 或 `largest-fallback` → 换更鲜艳衣服/靠近/调光，重录模板。

### T2 · 直线跟随（P0，10 min）
**布置**：10m 直道，地面每 1m 标记；主人背对车走。
**步骤**：手动模式先跑 5m ×3 记基线；再切跟随，主人以 **0.8–1.0 m/s** 走 10m。
**成功标准**
- 平均车速 **≥0.8× 手动基线**；
- **无停顿 >1.5s**（除主人停）；
- 人车距离维持 **1.7–3.5m**（视频/测距）；
- 5m 横向偏差 **≤0.3m**；
- 不丢锁、不撞墙。
**记录**：手动/跟随各 3 次的时间、距离曲线、丢锁次数。

### T3 · 转弯跟随（P0，10 min）
**布置**：L 型 90° 弯 + U 型 180° 掉头，转角留 ≥1.5m 回转空间。
**步骤**：主人正常步速过弯；车跟随。
**成功标准**
- 过弯全程主人 bbox 在画面 **≥90% 帧**；
- 若出画：**≤3s 重捕获**，不原地打转 >6s（`PIVOT_TIMEOUT_S`）；
- 不擦墙、不撞障碍；
- 方向反转 ≤3 次/5s（`REVERSAL_MAX`）。
**记录**：过弯耗时、出画时长、重捕获方式（TURN/BLIND/SEARCH）。

### T4 · passby 擦身（P0，核心，20 min）
**布置**：走廊宽 ≥1.5m；主人从车**正前**走向车侧再走到车后；横向 0.8 / 1.2 / 1.5m 三档；步速 0.6（慢）/ 0.9（正常）两档。
**步骤**：每档 ×2 次（左/右各一次）；记录车是否转、转到多少、是否停。
**成功标准**
- 主人可见期间**不出现 >1.0s 的停住**；
- 主人 bbox 在画面 **≥90% 帧**，最长连续缺失 **≤0.5s**；
- 车会朝主人侧转（θ 符号正确），**不反向**；
- 最小横向净空 **≥0.6m**；
- 全程**不换主**（路人/主人身份不串）；
- 若丢人：**≤2.4s** 进入 wait_owner，不盲目前冲。
**失败/中止**：转 30° 就停、反向转、贴人 <0.6m、换主 → 立即 STOP，记录帧号。
**记录**：三档 × 两速 × 左右 = 12 条；每条记"停住次数/最长停顿/出画时长/净空/是否换主"。

### T5 · 双人 / 路人干扰（P0，10 min）
**布置**：主人与路人同框；路人从车与人之间横穿，或比主人更靠近车 3s。
**步骤**：路人横穿 3 次；路人站到主人前面 3s；两人交错走。
**成功标准**
- 锁定主人 **≥95% 帧**；**0 次换主**；
- 路人更近时**不锁路人**（换人确认门生效）；
- 若误锁：**≤2s** 恢复主人。
**记录**：每次的 owner.json bbox 与两人真值对照。

### T6 · 静止 / 停等（P0，10 min）
**布置**：主人走 5m 后停下 5s，再走。
**步骤**：正常跟随 → 主人停 → 5s → 主人走。
**成功标准**
- 主人停后 **≤1.5s** 车停；
- 停住后位移 **<0.1m**（不顶人、不蠕行）；
- 人车距离 **≥1.2m**（`near_dist_m`）；
- 主人再走 **≤1s** 恢复跟随。
**记录**：停车延迟、停后位移、恢复延迟。

### T7 · 遮挡 / 丢人（P0，10 min）
**布置**：柱子/门框/拐角；主人躲 3s；另一次主人直接出画 5s。
**步骤**：遮挡 3s → 出现；出画 5s → 回来。
**成功标准**
- 遮挡期：车不胡乱加速，**前冲 <0.3m**；
- 出现后 **≤3s 重捕获**；
- 出画 5s：**≤2.4s** 进入 `wait_owner/lost_stop`，**不持续前进**；
- 全程不撞障碍。
**记录**：进入 wait 的时间、重捕获时间、期间位移。

### T8 · 手动兜底（P0，10 min）
**布置**：10m 直道 + 90° 弯；手机/网页遥控。
**步骤**：F/B/L/R 各 3s；直线 5m；跟随中一键切手动。
**成功标准**
- 手动 F/B 能带动载物盒（不堵转）；
- 5m 直线偏差 **≤0.3m**（IMU 航向保持）；
- `STOP` 0.5s 内停；
- 跟随→手动接管 **≤1s**，不失控。
**记录**：电流/电压（如有）、直线偏差、接管延迟。

### T9 · HIDE 选点（P1，需 world+HRI+动作层，20 min）
**布置**：走廊 + 门 + 饮水机/冰箱；车在主人身后 2m。
**步骤**：主人静止 20s（`hide_after_s`）→ WAIT→HIDE → 车自行挪到墙根；重复 3 次。
**成功标准**
- **3/3** 触发 WAIT→HIDE；
- 落点靠墙、**不挡门/不挡家电正面**（离门中心 ≥1m）；
- 落点主人回望**可见**（或至少在选中扇区）；
- 全程不撞、不卡死；到达后 `parked=True`。
**失败/中止**：grid 陈旧 / 动作层未接 → 标记 P1 未就绪，不阻塞 P0。

### T10 · RECEIVE 递物（P1，需 HRI+动作层，15 min）
**布置**：主人在 HIDE 车旁，持**水瓶/玩偶**（不用果冻）缓近。
**步骤**：持物靠近 → 车 APPROACH → 合拢 → 停。
**成功标准**
- **3/3** 进入 RECEIVE；
- 最终间距 **0.3–0.5m**，不撞人；
- 交接后 `receive_exit_s(0.8s)` 退出，回 WAIT；
- 超声 20cm 急停不被误触发（或触发后能恢复）。
**记录**：触发距离、最终间距、误触发次数。

### T11 · 全流程 8 分镜（P0 目标，P1 依赖，40 min/次）
**布置**：按 `DEMO_PLAN.md` 动线；安全员 + 路人 + 递物演员。
**步骤**：完整 8 分镜连跑，不中途救场。
**成功标准**
- **连续 3 次**不救场完成；
- 总时长 **≤3 min**；
- 每个分镜达到其单项标准（见 §4）；
- 黑匣子 jsonl 完整；视频可剪。
**失败/中止**：任一 P0 分镜失败 → 记录失败点，回到对应单项场景复训。

### T12 · 故障注入（P1，10 min）
**步骤**：拔/插 C3；拔/插相机；重启 rk-control；切手动。
**成功标准**
- C3 watchdog **≤10s** 恢复；
- 相机自愈 **≤5s** 恢复出图；
- 服务重启后 HTTP/串口恢复；
- 任意时刻手动接管有效。
**记录**：恢复时间、是否需人工二次插拔。

## 5. demo 视频录制方案

### 5.1 器材与参数
- 主机位：手机/微单，**1080p60**，固定白平衡；副机位：运动相机（跟拍/低角度）。
- 收声：环境声即可；**不要现场加音乐**（后期配）。
- 光线：白天均匀光；避免窗户逆光；必要时补一盏柔光。
- 存储：每镜 3 条 take；拍完立刻备份。

### 5.2 机位（文字版）
```
        [门]
         │
   ┌─────┴─────┐
   │  走廊      │   A: 主人 POV（回头看车）
   │            │   B: 第三人称侧后方（看车+人）
   │   C: 固定广角（看 HIDE/等待点）   │
   │   D: 低角度贴地（看轮子/转向）     │
   └────────────┘
```
- **A 主人 POV**：手持，回头拍车（分镜 1/8）。
- **B 第三人称**：侧后方 2–3m，拍人车关系（分镜 2/4/6）。
- **C 固定广角**：拍 HIDE 选点/等待（分镜 3/5）。
- **D 低角度**：拍转向/轮速/接物（分镜 7，B-roll）。

### 5.3 分镜拍摄表

| # | 镜头 | 机位 | 时长 | 关键动作 | 备选 |
|---|---|---|---|---|---|
| 1 | 跟出宿舍门 | A + B | 8–10s | 主人出门，车跟 2.5–3m | 手动跟拍 |
| 2 | 打水停车 | B + C | 6–8s | 主人停 5s，车减速停 | 固定机位 |
| 3 | HIDE 挪到墙根 | C | 10–12s | 车自行挪到墙根 | 后期加速 |
| 4 | 路人擦身 | B + 低角度 | 8–10s | 路人横穿，车锁主不跟 | 慢动作回放 |
| 5 | 冰箱取物 | C | 6–8s | 主人出画，车不误唤醒 | 固定 |
| 6 | 持物靠近 | B | 6–8s | 主人拿水瓶走近 | 近景 |
| 7 | 上前接住 | D + B | 6–8s | 车 APPROACH 到 0.3–0.5m | 慢动作 |
| 8 | 回程跟随 | A + B | 10–12s | 车掉头跟上到门口 | 跟拍 |

### 5.4 拍摄顺序（按场景批量，不按剧本顺序）
1. 先拍 **B-roll**（车体/传感器/屏幕/轮子/标定/启动）——不依赖演出。
2. 再拍 **T4 passby**（最难的先拍，状态好）。
3. 再拍 **T2/T3/T6/T7**（跟随素材）。
4. 最后拍 **T9/T10**（若已接线）。
5. 每条 take 记"场景 ID + take 号 + 结果"，避免后期找不到。

### 5.5 失败重拍规则
- 单镜 **3 条 take**；取最好一条。
- 出现安全事件（贴近 <0.5m、撞、换主）→ 立即停，重来，不剪进去。
- 真跑不通的镜头 → **手动模式补拍** + 字幕标注"手动兜底"，不假装自主。

### 5.6 隐私与安全
- 路人演员知情同意；不拍无关人员正脸。
- 拍摄时安全员全程在车侧 1m 内，手放急停。
- 不在楼梯/坡道/湿滑地面拍摄。
